# Task 5.2 - Nugget staging

## Objective

Implement repository-mode `alloy build sdk` nugget staging for builtin,
local, and VCS nugget sources into the product build motherlode.

## Design Grounding

- Alloy owns staging and VCS operations; Smelterl only reads an already staged
  motherlode.
- The builtin `nuggets/` repository is now real bootstrap metadata and must be
  staged first under `motherlode/builtin/`.
- Command-layer `--allow-dirty` and `ALLOY_ALLOW_DIRTY` must be resolved before
  VCS helper calls so staging receives an explicit dirty policy.

## Initial Task 5.3 Status Check

Task 5.3 was marked done, but the implemented migration scope covers the
Smelterl checkout/submodule prerequisite path only. The remaining
resolve/build/cache/export behavior for a Smelterl executable is not present in
Alloy yet, so Task 5.3 was returned to TODO with a partial-status note.

## Outcome

`alloy build sdk` now stages nugget repositories into
`$ALLOY_MOTHERLODE` after workspace setup:

- builtin nuggets are staged first under `motherlode/builtin/`,
- additional local paths from `ALLOY_NUGGET_PATH` and `-n/--nugget-path` are
  copied in deterministic order,
- VCS sources in `git+URL#ref` form are cloned or validated through
  `vcs_clone_or_validate`,
- destination basename conflicts are resolved with `_2`, `_3`, ... suffixes.

The command-layer dirty policy remains explicit. `--allow-dirty` and
`ALLOY_ALLOW_DIRTY` are normalized to `true|false` before staging; local dirty
Git nugget repositories fail by default, and VCS clone validation receives the
same explicit policy.

## Notes

Local directory staging excludes `.git/` and writes `.alloy_repo_info` into the
staged copy when provenance can be read from the source checkout. This gives
Smelterl stable provenance input without copying full local Git metadata into
the motherlode.

Validation passed through the full gate, including Smelterl Common Test. The
full gate still reports only the pre-existing non-blocking ShellCheck warnings
in the legacy `build-firmware.sh`.
