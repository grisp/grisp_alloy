## Key Decisions
- Implemented a new root `alloy` script as the canonical CLI entrypoint.
- Global option parsing was implemented directly in `alloy` with command-agnostic extraction and normalized exports (`ALLOY_DEBUG`, `ALLOY_TRACE`, `ALLOY_DEV_MODE`, Vagrant flags, `ALLOY_FORWARD_ENV`).
- Command dispatch uses `scripts/commands/<verb>-<noun>.sh` first, then `scripts/commands/<verb>.sh` fallback.
- Added lightweight command wrappers in `scripts/commands/` to bridge to the existing legacy scripts, preserving current behavior while enabling new dispatch structure.

## Unexpected Issues And Resolution
- Initial noun extraction consumed the second token for single-word commands (e.g. `alloy ping pong`), dropping intended positional args.
- Resolved by selecting noun only when a matching `<verb>-<noun>` handler actually exists.
