## Objective
Implement global once-per-nugget execution for `pre_build` hooks across all SDK targets, preserving deterministic first-encounter order while improving debug observability.

## Key Decisions
- Execute `pre_build` hooks from `build-sdk.sh` immediately after each target `smelterl generate` pass so ordering follows the established target traversal sequence.
- Use a global per-build dedup map keyed by nugget identifier to enforce once-only execution across all targets.
- Keep hook-run visibility at `INFO` level (`-d`) and place aggregate pre_build counters in `DEBUG` level (`-dd`) summary output.
- Count and report dedup skips and missing hook scripts in the debug summary to make multi-target behavior auditable without increasing `-d` verbosity.
