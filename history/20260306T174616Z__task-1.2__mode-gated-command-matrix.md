## Key Decisions
- Implemented mode-gating with centralized command metadata (`COMMAND_MATRIX`) in `alloy`, then reused that metadata for both dispatch validation and global help rendering.
- Enforced required matrix entries from planning refinement:
  - `prepare sdk` fails in repository mode,
  - `build sdk` fails in SDK mode.
- Updated `alloy --help` command listing to show only commands available in the current mode, preventing help/validation drift.

## Unexpected Issues And Resolution
- Existing single-word dispatch test used a synthetic `ping` command not present in the real command matrix, which correctly failed once matrix validation was centralized.
- Resolved by switching the test to a real single-word command path (`grispio`) while keeping the dispatch behavior assertion.
