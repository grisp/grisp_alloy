## Objective

## Key Decisions
- Added a standalone `scripts/utils/debug_utils.sh` with internal orchestrator functions: `log_error`, `log_warn`, `log_info`, `log_debug`, `die`, `set_debug_level`, `set_trace`, `enter_hidden`, `leave_hidden`.
- Integrated top-level `alloy` with shared debug utilities by sourcing `scripts/utils/debug_utils.sh` and replacing inline debug/trace export logic with `set_debug_level` + `set_trace` calls.
- Kept command availability matrix logic from Task 1.2 intact while extending tests to validate this integration path.
