# Task Context: 5.12c

## Objective
Update `alloy build sdk` summary output path ergonomics so paths under the current working directory print as relative paths, while paths outside the current working directory remain absolute.

## Outcome
Implemented root-relative path formatting for `alloy build sdk` summary output and Alloy-owned command logs.

- Added `display_path_for_root ROOT_DIR PATH_VALUE` to `scripts/utils/file_utils.sh`.
- Updated `build_sdk_print_summary` to format all summary path lines through that helper.
- Updated Alloy-owned `build-sdk` info/debug logs and SDK packer RPATH-scan logs to format paths through the same root-relative policy.
- Kept behavior scoped to `build sdk` summary output only (no broader logging migration).

## Design Decisions
- Reused shared path utilities (`normalize_path`, `relative_path`) to avoid command-local path math drift.
- Kept relative input paths unchanged and only relativized absolute paths when they are inside the provided root directory.
- Enforced path-boundary correctness (`/root` does not match `/root_extra`) when deciding whether a path is inside the root.
