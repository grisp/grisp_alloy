## Key Decisions
- Added `scripts/utils/console_utils.sh` as the shared orchestrator-side
  console formatting layer and moved user-facing print helpers there
  (`print_result`, `print_note`, `print_hint`).
- Kept dependency flow explicit and acyclic:
  - `common.sh` sources `console_utils.sh` and `debug_utils.sh`,
  - `debug_utils.sh` also sources `console_utils.sh` directly,
  - no `debug_utils.sh -> common.sh` dependency.
- Standardized include-guard pattern for sourced utility files touched in this
  task (`common.sh`, `debug_utils.sh`, `console_utils.sh`) to make repeated
  sourcing idempotent.
- Migrated orchestrator log formatting to `console_utils.sh` (`console_print_to`
  path), enabling consistent ANSI behavior for both log and print output.
- Added dedicated console utility tests plus debug/common test updates for new
  behavior and compatibility.

## Unexpected Issues And Resolution
- Initial NO_COLOR tests falsely forced color output because test stubs replaced
  `console_supports_color` with an unconditional success function.
- Resolved by using test stubs that still honor `NO_COLOR`, so tests validate
  both color-enabled and color-disabled branches correctly.
