# Task Context: Task 5.8

## Objective
Implement per-target Buildroot build execution in `alloy build sdk`:
- run `make <target_defconfig>` then `make` for each generated target,
- preserve target isolation via target-local `O=` and `BR2_EXTERNAL=`,
- generate per-target `make_alloy` helper scripts for manual Buildroot debugging.

## Scope and Constraints
- Owner repository: `grisp_alloy`.
- Follow `docs/03_ALLOY_DESIGN.md` SDK build flow step for Buildroot execution.
- Keep legal-info execution out of this task (belongs to Task 5.9).
- Add/adjust command-level integration tests in `scripts/tests/test_build_sdk_command.sh`.

## Initial Plan
1. Add Buildroot execution function(s) and wiring in `scripts/commands/build-sdk.sh`.
2. Add generation of target-local executable `make_alloy` helper.
3. Extend tests to verify make invocation arguments/order and helper behavior.
4. Run focused tests, then full relevant gates.

## Outcome
- Implemented per-target Buildroot execution in `scripts/commands/build-sdk.sh`.
- For each target in plan order (auxiliaries then main), Alloy now runs:
  1. `make <target_id>_defconfig`
  2. `make`
  with target-local `O=` and `BR2_EXTERNAL=` plus required `ALLOY_*` context.
- Added generation of target-local executable `workspace/make_alloy` helpers
  that forward arbitrary make goals using the same context as orchestrator
  builds.

## Design Decisions
- Load `alloy_context.sh` per target before Buildroot execution so
  `ALLOY_CONFIG_BUILDROOT_PATH` remains the source of truth from Smelterl
  output rather than recomputing Buildroot locations in bash.
- Keep legal-info generation out of this task; that remains owned by Task 5.9.
- Include `V=1` only when `ALLOY_DEBUG >= 3`, aligning with design verbosity
  rules and preserving default output behavior.
