## Key Decisions
- Implement SDK packing in `build-sdk.sh` as a post-consolidation step so the
  existing plan/generate/build/legal pipeline remains unchanged and packing is
  an explicit final phase.
- Keep Task 5.12a focused on packaging plus text relocation markers
  (`.alloy_relocation_manifest`, `.alloy_sdk_dir`) and defer ELF RPATH
  hardening to Task 5.12b.
- Build the packed SDK from the main target workspace (`host/`, `images/`,
  `staging/`) plus staged manifest/legal/auxiliary outputs and repository
  scripts/alloy entrypoint.

## Unexpected Issues And Resolution
- Fixture-based `build-sdk` tests failed after packing was enabled because the
  local command fixture did not include an `alloy` entrypoint and the fake
  Buildroot Makefile did not create `host/images/staging`. Updated test
  fixtures to include `alloy` and to populate those workspace directories.
