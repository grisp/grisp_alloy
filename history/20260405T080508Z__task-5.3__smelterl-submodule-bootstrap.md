## Key Decisions

- Kept repository mutation explicit: repository-mode `alloy build sdk` now
  fails fast when `smelterl/` is missing and only initializes it when the user
  opts in with `--init-deps`.
- Switched `.gitmodules` to the HTTPS Smelterl URL so fresh clones and CI do
  not require GitHub SSH access for a read-only checkout.
- Ran `git submodule sync` before `git submodule update` in explicit init
  paths so existing local clones pick up the URL change in `.gitmodules`.
- Added a dedicated GitLab validation job that syncs/initializes submodules
  before running the full gate, instead of hiding repository mutation inside
  normal command execution.
- Added a GitHub Actions validation workflow for the repository currently used
  on GitHub so the same submodule/bootstrap path is exercised on pushes and
  pull requests there as well.
