# Task 5.11 - Main legal/manifest consolidation pass

## Objective
Implement the SDK-build main consolidation pass so Alloy performs a final main-target `smelterl generate` with repeatable `--buildroot-legal` inputs and produces staged merged legal export + `ALLOY_SDK_MANIFEST`.

## Scope and design anchors
- `docs/03_ALLOY_DESIGN.md` §5.5 SDK Build Flow
- `smelterl/docs/DESIGN.md` generate main-only legal/manifest options
- `docs/01_DATA_DESIGN.md` staging/manifest/legal layout contracts

## Initial implementation plan
1. Add a post-legal-info consolidation step in `scripts/commands/build-sdk.sh`.
2. Invoke main-target `smelterl generate` with `--output-manifest`, repeatable `--buildroot-legal`, and optional `--export-legal`/`--include-sources`.
3. Validate resulting staging outputs (`ALLOY_SDK_MANIFEST`, merged `legal-info/`).
4. Update command summary messaging to reflect completion of consolidation.
5. Extend `scripts/tests/test_build_sdk_command.sh` to assert argument contract and call ordering.

## Outcome
- Implemented `build_sdk_run_main_consolidation` in `scripts/commands/build-sdk.sh` and wired it after per-target legal-info generation and sdk-output injection.
- Main consolidation now invokes `smelterl generate` with:
  - `--output-manifest ${ALLOY_SDK_STAGING_DIR}/ALLOY_SDK_MANIFEST`
  - `--export-legal legal-info`
  - repeatable `--buildroot-legal` for every target in plan order
  - `--include-sources` when requested by `alloy build sdk --include-sources`.
- Added strict validation for expected consolidation outputs in staging:
  - `ALLOY_SDK_MANIFEST` must be present/non-empty
  - merged `legal-info/` must exist.
- Updated command summary output to include staged manifest/legal-info paths and removed the obsolete “manifest consolidation follows later” hint.
- Updated Buildroot execution selection in `build-sdk` so target defconfig/build and legal-info calls prefer `BUILDROOT_DIR/utils/brmake` when `ALLOY_DEBUG=0`; debug levels above zero keep direct `make` for higher-visibility troubleshooting.

## Test updates
- Extended `scripts/tests/test_build_sdk_command.sh` to verify:
  - consolidation invocation arguments in fake Smelterl logs,
  - staged manifest/legal-info output creation,
  - include-sources forwarding to consolidation generate pass,
  - `brmake` usage at default debug level and `make` behavior retention at higher debug levels.
- Updated fake Buildroot fixture Makefile to create `workspace/legal-info/` on `make legal-info` so consolidation preconditions match real behavior.
- Updated fake Smelterl generate handlers (both direct and rebar-built fixture paths) to accept main-only legal/manifest options used by consolidation.
