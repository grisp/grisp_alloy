## Key Decisions

- Replaced the transitional command wrapper with a self-contained Task 5.1
  command implementation instead of continuing to delegate to the legacy
  repository-root `build-sdk.sh`. This keeps the canonical `alloy build sdk`
  UX and new workspace layout under one command-layer source of truth while
  leaving later Smelterl/Buildroot orchestration tasks to extend the same
  script.
- Kept the parser on the shared `scripts/argparse.sh` contract and removed the
  overloaded `-c` spelling from the final contract. `-c` now means only
  `--clean`; package cleanup uses long-only `--clean-package PKG`.
- Exported `ALLOY_SDK_BUILD_DIR`, `ALLOY_SDK_PLAN_DIR`,
  `ALLOY_SDK_TARGETS_DIR`, `ALLOY_SDK_STAGING_DIR`, and `ALLOY_MOTHERLODE`
  during workspace setup so later Phase 5 tasks can reuse the command-layer
  path calculation instead of re-deriving product-local build roots.
- Kept self-bootstrapping for direct command execution, but limited mode
  inference to one meaningful use: detect SDK mode and fail early. The command
  now sets only repository paths because `build sdk` is a repository-only
  operation.

## Unexpected Issues And Resolution

- The first `./scripts/tests/gates/full.sh` run failed inside
  `smelterl_legal_SUITE` because stale `/tmp/smelterl-legal-export*`
  directories from earlier runs caused the suite's export-path collision checks
  to fire before the new Alloy shell changes were exercised there. Clearing the
  stale test temp directories and rerunning the affected Smelterl legal suite
  restored the expected green full-gate result.
- Human review identified that the earlier attempt to support both `-c` and
  `-c VALUE` was a contract workaround hiding a design inconsistency. The final
  task resolution was to choose one unambiguous short-option meaning, update
  the design accordingly, and codify the escalation rule in `AGENTS.md` and
  `docs/WORKFLOW.md`.

## Design Changes

- Clarified `docs/03_ALLOY_DESIGN.md` §3.1 so `--clean-package PKG` is
  long-only and `-c` is reserved exclusively for `--clean`.
- Updated `AGENTS.md` and `docs/WORKFLOW.md` so requirement or contract
  incoherence must be escalated to the human before implementation rather than
  hidden behind compatibility workarounds.
