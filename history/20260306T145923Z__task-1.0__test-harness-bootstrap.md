## Key Decisions
- `scripts/tests/` is bash-only.
- Smelterl/Erlang tests are delegated from the full gate to the Smelterl directory when present; they are not hosted in `scripts/tests/`.
- `shellcheck` runs in the full gate when available; findings are warning-only by default and strict via `ALLOY_SHELLCHECK_STRICT=1`.

## Unexpected Issues And Resolution
- `bash_unit` executed helper functions because helper names started with `tests_`.
- Resolved by renaming helper API to `harness_*`.
