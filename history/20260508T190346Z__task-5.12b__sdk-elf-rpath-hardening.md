# Task Context: Task 5.12b - SDK ELF RPATH verification and hardening

## Started
- Timestamp (UTC): 2026-05-08T19:03:46Z
- Planning item: Task 5.12b (`docs/PLANNING.md`)

## Goal
Implement pack-time SDK ELF RPATH verification/fixup using `patchelf`, fail on unresolved/non-relocatable cases, and add deterministic logging + focused tests.

## Initial Observations
- `scripts/utils/sdk_utils.sh::pack_sdk` currently performs text-path sanitization and archive creation but does not verify/fix ELF RPATHs.
- Design requires a pack-time verification/fixup pass across embedded SDK trees.

## Planned Files
- `scripts/utils/sdk_utils.sh`
- `scripts/tests/test_sdk_utils.sh`
- optionally `scripts/tests/test_build_sdk_command.sh` for integration failure surfacing.

## Implemented
- Added `verify_elf_rpaths SDK_DIR` in `scripts/utils/sdk_utils.sh`.
- Added pack-time ELF scan + RPATH validation/fixup across `host/`, `images/`,
  `motherlode/`, and `staging` when present.
- Enforced `$ORIGIN`-relative RPATH entries; rewrote fixable SDK-internal
  absolute entries to `$ORIGIN`-relative paths via `patchelf --set-rpath`.
- Added strict failures for malformed RPATH lists, unfixable entries, and
  post-rewrite non-relocatable entries.
- Wired `verify_elf_rpaths` into `pack_sdk` before text-path sanitization.
- Added focused `test_sdk_utils.sh` coverage for valid, rewritten, and
  unfixable RPATH cases using a deterministic fake `patchelf` fixture.
- Refined non-dynamic ELF handling to skip `patchelf` probe failures for
  object-file/non-dynamic cases observed in real builds (including
  `patchelf: wrong ELF type`).
- Excluded target sysroot ELF paths from SDK host-RPATH hardening
  (`host/<triplet>/sysroot/...` and target staging paths) so target runtime
  RPATHs do not fail host-tool relocatability checks.
- Replaced raw-byte ELF magic probing with a hex-based check to avoid bash
  null-byte substitution warnings during full-tree scans.
- Added focused `test_sdk_utils.sh` coverage for `wrong ELF type` skips and
  target-sysroot skip behavior.
